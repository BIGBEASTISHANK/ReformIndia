# Reform India

Reform India is an open-source platform for documenting, discussing, and evaluating reforms that could improve governance, policing, media, public institutions, and accountability in India.

The project focuses on practical ideas, open discussion, and constructive criticism rather than political parties or personalities.

## Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
* Framer Motion
* Giscus

## Contributing

Suggestions, corrections, and new reform proposals are welcome through discussions and pull requests.

## Note

The reform ideas originate from the site owner. AI may be used to improve grammar, clarity, and presentation while preserving the original intent.
